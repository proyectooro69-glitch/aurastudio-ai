# Base44 Dev Environment

## Stack
- Vite 8 + React 19 + TypeScript + TanStack Start (SSR + prerender)
- Tailwind CSS v4 (via `@tailwindcss/vite` plugin, not PostCSS)
- Blink SDK (`@blinkdotnew/sdk`) — hardcoded fallback project ID & publishable key in `src/blink/client.ts`, no env vars required to boot
- No database, no backend, no external services

## Running
- `docker compose -f docker-compose.base44.yml up -d`
- Node 22 slim image; `npm install --legacy-peer-deps` runs at container start, then `npm run dev` (Vite dev server on port 3000)
- Source is bind-mounted; HMR is enabled (with polling via `CHOKIDAR_USEPOLLING=true` for bind-mount reliability)
- `node_modules` is a named volume to avoid host/container conflicts

## Key files
- `vite.config.ts` — custom plugins: `blinkEnsureRootCss` (guarantees `index.css` import in `__root.tsx`), `blinkRouteTreeHealth` (detects stale route tree generation), Blink picker runtime
- `src/routes/index.tsx` — main landing page (AuraStudio AI image/video generation UI)
- `src/routes/app/` — dashboard pages under `/app` segment
- `src/routes/__root.tsx` — root document, SSR shell, global providers
- `src/routeTree.gen.ts` — auto-generated by TanStack Start, do not edit

## Verification
- `curl -s -o /dev/null -w "%{http_code}" http://localhost:3000/` should return 200
- Page title: "AuraStudio AI · Visual content, elevated"
- No environment variables or secrets required
